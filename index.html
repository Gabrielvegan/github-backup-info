GitHub Backup

自用的 GitHub 專案備份工具，由 GitHub 使用者 Gabrielvegan 管理。

工具透過 GitHub Actions，將明確選定的 Git 儲存庫及其 LFS 物件打包、加密並備份到擁有者授權的 Google Drive，協助日後還原。

Google Drive 授權用途

僅要求 drive.file 權限，供建立及讀寫這個應用程式建立或經使用者授權的備份檔案。執行前會核對目的 Google 帳號，未符合指定帳號時停止上傳。

本工具供擁有者自用，沒有對外註冊或購買服務。這個公開頁面只提供工具說明，不提供私人儲存庫、備份內容或存取憑證。
