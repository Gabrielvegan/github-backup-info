GitHub Backup 隱私權政策

生效日期：2026-10-22。管理者：GitHub 使用者 Gabrielvegan。本政策適用於其自用 GitHub Backup 工具。

存取的資料與用途

工具讀取擁有者選定的 GitHub 儲存庫、Git 歷史與 LFS 物件，製作備份。透過 Google Drive API 取得登入帳號的電子郵件地址，以核對備份目的帳號；使用 drive.file 權限建立、讀寫應用程式建立或經授權的備份檔案，並下載驗證備份完整性。

儲存與保護

備份在 GitHub Actions 暫存環境處理，上傳到 Google Drive 前以 rclone crypt 加密。OAuth 憑證與加密設定由管理者保存在本機專用設定檔及 GitHub Actions Secrets；不應放入公開程式碼、紀錄或聊天訊息。執行紀錄可能包含專案名稱、大小、時間與成功或失敗狀態。

資料使用與服務提供者

資料僅用於備份、完整性驗證與還原，不出售、不用於廣告、也不用於訓練 AI 模型。GitHub 提供程式碼託管與 Actions 執行環境；Google 提供 OAuth 授權及 Drive 儲存服務。各服務依其政策處理相關資料。備份不會由本工具主動公開分享。

保留與刪除

目前版本保留歷史備份，不自動刪除。管理者可在 Google Drive 手動刪除備份；如需永久移除，亦須處理垃圾桶。撤銷 OAuth 授權會停止後續存取，不會自動刪除既有備份。GitHub Actions 紀錄依帳號或儲存庫設定保留。

停止授權

可透過 Google 帳號的第三方連線管理撤銷本工具存取權，並停用 GitHub Actions 排程、移除儲存的憑證。

公開說明頁面

頁面本身不包含分析、廣告或追蹤程式。公開網站託管服務仍可能依其政策保留基本連線紀錄。
